## About

## Hiiiii!!! Welcome to Pulse Nepal!!!!!!!!

### Pulse Nepal is a website/ national weather monitoring system, I created to explore weather conditions across Nepal's 77 districts. The main idea behind this project is to make weather information easier to access and understand in one place.

### This project will help my fellow locals and nepalis to get latest weather update

## Built With

- HTML
- CSS
- JavaScript
- Open-Meteo API for weather data

## 📂 Files

Here are some of the files used in this project!

- `main.html` — The main page of Pulse Nepal.
- `sun.html` — The temperature page.
- `sun.css` — Styling for the temperature page.
- `sun.js` — Loads and displays temperature data.
- `rain.html` — The rainfall page.
- `rain.css` — Styling for the rainfall page.
- `rain.js` — Loads and displays rainfall information.
- `flood.html` — The flood information page.
- `flood.css` — Styling for the flood page.
- `flood.js` — Handles the flood page's information and display.



## To  Run It Locally
1. Download or clone this repository.
2. Open the project folder in VS Code.
3. Open `main.html` in your browser, or use the Live Server extension in VS Code.
4. Make sure you have an internet connection so the weather data can load.
